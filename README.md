# Anota Treino — Plugin da Biblioteca (Penpot)

Plugin que reconstrói a biblioteca de componentes do Anota Treino no Penpot, com auto layout e componentes aninhados.

Para instalar no Penpot: abra o arquivo, use Ctrl+Alt+P e cole o endereço
https://estudio-orsi.github.io/anota-treino-plugin/manifest.json
